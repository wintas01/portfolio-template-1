# Portfolio Template 1 — Neon Tech

A single-file, animated portfolio website with a dark neon look. No build step and no dependencies — just open `index.html`.

## Animations
- **Cinematic scroll** — line-by-line headline reveal, word-by-word "About" text, pinned horizontal project gallery, scroll progress bar
- **3D / particles** — interactive particle field that reacts to the mouse, 3D tilt + shine on project cards
- **Kinetic typography** — scroll-reactive marquees, scrambling role text, hover-lifting "LET'S TALK" letters
- **Minimal & smooth** — custom cursor, magnetic buttons, 0→100 preloader

## Customise
All content is placeholder. Search `index.html` for:
- `Your Name`, `Your City`, `hello@yourname.com`
- Project titles (`Project One` … `Project Four`) — replace the `.art` blocks with your screenshots
- Social links in the footer

The contact form is a demo — connect it to a form service (e.g. Formspree) before going live.

## Deploy
Works on GitHub Pages: **Settings → Pages → Deploy from branch → `main` / root**.
